# Download

## Latest Stable Release

Stable releases are built from the `main` branch and are the recommended downloads for usual desktop app users. Rivet publishes stable Windows installers plus separate native macOS disk images for **Apple Silicon** and **Intel** Macs. Choose the one that matches the chip shown in **Apple menu > About This Mac**.

## Latest Developer Release

Developer releases are built from the `develop` branch. They are useful for trying the newest Rivet 2 work before it becomes the stable release, with Windows plus native Apple Silicon and Intel macOS builds published when the branch workflow succeeds.
