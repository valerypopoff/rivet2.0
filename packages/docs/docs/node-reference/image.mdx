## Overview

The Image Node creates an `image` value from binary data or raw base64-encoded image bytes. **Image source** defaults to **Binary data**, preserving the behavior of existing projects. Select **Base64** to paste encoded bytes into a code field or supply them through an input port. **Media Type** describes the decoded image (PNG, JPEG, or GIF) in either mode.

In Binary data mode, provide the image bytes in either of two ways:

- Directly in the node's editor settings, using **Pick Image**. The settings show that an image is selected without displaying a thumbnail.
- Dynamically, by clicking **Use an input port for Image** and connecting a `binary` value to the `Data` port.

In Base64 mode, paste the raw base64 string in the **Base64** code field, or click **Use an input port for Base64** and connect a `string` value to the `Base64` port. The source-mode switch shows only the port for the selected mode; switching back to Binary data makes the existing `Data` port available again.

The media type can also be provided in two ways:

- Directly in the node's editor settings, using the dropdown menu.
- Dynamically, by connecting another node to the Image Node's `Media Type` input port.

The node body summarizes the selected source and media type. After the node runs, its output shows a fitted image preview; open the fullscreen output to inspect the image without the inline preview size limit.

To encode the resulting image bytes as a raw base64 string, connect the **Image** output to a [To Base64 node](./to-base64.mdx). The same node can encode binary data directly without an Image node.

## Example 1: Create a static image

1. Create an Image Node.
2. In the node's editor settings, click on the `Pick Image` button. This will open the image browser.
3. Select an image from the image browser. The `Image` field will show a selected-file status, not an image preview.
4. Run the graph. The `Image` output of the Image Node should contain the selected image.

![Image Node Example 1](./assets/image-node-example-01.png)

## Error Handling

The Image Node errors if its selected source is missing or has the wrong input type. Base64 mode also errors on invalid base64. When the Media Type input port is enabled, it must receive a string. The node does not inspect the bytes to infer the media type; choose the matching type yourself.

## FAQ

**Q: Can I use the Image Node to display an image in the Rivet UI?**

A: Yes, the Image Node can be used to display an image in the Rivet UI. The image will be displayed in the node's output port when the graph is run.

**Q: Can I use the Image Node to convert a binary type into an image?**

A: Yes, you can use the Image Node to convert a binary type into an image. You will need to provide the binary data to the `Data` input of the Image Node and set the `Media Type` to the appropriate type for the image.

**Q: What image formats are supported by the Image Node?**

A: The Image Node supports PNG, JPEG, and GIF formats.
