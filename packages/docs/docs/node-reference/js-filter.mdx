# JS Filter Node

The JS Filter node filters an input array with a JavaScript callback body.

The callback body can use `item`, `index`, and `array`, and should `return` a truthy value for items that should stay in the output.

## Inputs

| Title | Data Type | Description          |
| ----- | --------- | -------------------- |
| Array | `any[]`   | The array to filter. |

Additional inputs are created from `{{name}}` interpolation tokens in the callback body. A path expression such as `{{config.limit.max}}` creates only `config`; `{{item.name}}` and `{{array[0]}}` select from the callback's local values and create no extra input.

Use `{{@globals.variableId}}` or a JSONPath expression such as `{{@globals.rules.minimum}}` to read the current global value without creating an additional input. It is read once when the node starts and is available to every callback invocation. The reference does not wait for or order Set Global; wire a writer explicitly when the filter must read a value that the graph assigns earlier in the run.

## Outputs

| Title    | Data Type | Description                             |
| -------- | --------- | --------------------------------------- |
| Filtered | `any[]`   | Items whose callback result was truthy. |

## Settings

| Setting       | Description                                                                 |
| ------------- | --------------------------------------------------------------------------- |
| Callback Body | JavaScript callback body. Use `return` to decide whether each item remains. |

## Example

```js
return item != null;
```
