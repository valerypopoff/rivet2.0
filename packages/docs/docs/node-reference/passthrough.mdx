## Overview

The Passthrough node is an executable value relay: every connected `Input [i]`
is emitted unchanged from `Output [i]`. Use it when a value belongs on an
actual workflow path or when you need a readable, local fan-out point.

For a compact canvas rail that shares values broadly without adding an
executable relay, use [Data Bus](./data-bus.mdx) instead.

## Inputs

| Title | Data type | Description | Notes |
| --- | --- | --- | --- |
| Input [i] | `any` | The ith input to pass through. | Ports are added as connections are made. |

## Outputs

| Title | Data type | Description | Notes |
| --- | --- | --- | --- |
| Output [i] | `any` | The ith input value, unchanged. | Mirrors the corresponding connected input. |

## Settings

Passthrough has no node-specific settings.

## Error handling

Passthrough does not transform or validate values. If an input is missing, its
matching output is absent.
