## Overview

The Set Global Node is used to set a global value that is shared across all graphs and subgraphs during an execution in Rivet. This can be useful for storing and retrieving values that need to be accessed by multiple graphs.

On the canvas, the node title shows a downward arrow icon so it is easier to distinguish from [Get Global](./get-global.mdx). This icon is only a visual title cue.

The Set Global Node allows you to specify the ID of the global value and the value itself. The ID can be either a fixed string or an input value. The value can be of any data type. Fixed IDs and configured project global variables in Project settings → General appear as suggestions in [Get Global](./get-global.mdx)'s searchable Variable ID field so you can choose them without retyping. A Set Global node can overwrite a configured project global variable during its run; its `Previous Value` then returns the automatically assigned value.

Interpolation-capable nodes can read the current value directly with `{{@globals.variableId}}` or a JSONPath expression such as `{{@globals.profile.user.name}}`, without a Get Global node. That shorthand does not create an execution dependency or wait for this node, so connect the writer explicitly when a later read must observe this assignment.

## Inputs

| Title       | Data Type | Description                                                                                          | Default Value | Notes                                                                                                |
| ----------- | --------- | ---------------------------------------------------------------------------------------------------- | ------------- | ---------------------------------------------------------------------------------------------------- |
| Value       | Any       | The value to be set as the global value.                                                             | (required)    | The input will be coerced into the data type specified in the node's settings.                       |
| Variable ID | `string`  | The ID of the global value to be set. This input is only available if `Use Variable ID Input` is on. | (optional)    | The input will be coerced into a string if it is not a string. The ID must be unique in the context. |

</TabItem>

<TabItem value="outputs">

## Outputs

| Title | Data Type | Description | Notes |
| ----- | --------- | ----------- | ----- |
| `<variable ID>` (or `Value` when input-driven) | Any | The value that was set as the global value. | A fixed ID such as `Foobar` appears as `Foobar`. The output uses the same data type as the `Value` input. |
| `Prev value of: <variable ID>` (or `Previous Value` when input-driven) | Any | The previous value of the global variable before the new value was set. | A fixed ID such as `Foobar` appears as `Prev value of: Foobar`. If there was no previous value, Rivet returns the selected data type's default value. |
| Variable ID | `string` | The variable ID that was set. | Useful when the ID is supplied through the input port. |

The displayed output titles follow a fixed ID when you edit it. Existing wires stay attached because the ports keep their saved IDs. When the ID comes from the input port, the output titles remain `Value` and `Previous Value` and the node body says `ID from input`, because the runtime ID is not known in the editor.

</TabItem>

## Example 1: Set a global value

1. Create a [Text Node](./text.mdx) and set the value to `Hello, World!`.
2. Create a Set Global Node and set the ID to `greeting`.
3. Connect the Text Node to the `Value` input of the Set Global Node.
4. Run the graph. The `greeting` output of the Set Global Node should contain the value `Hello, World!`.

![Set Global Node Example 1](./assets/set-global-node-example-01.png)

## Error Handling

The Set Global Node will error if the `Value` input is not provided or if the ID of the global value is not provided or not unique.

## FAQ

**Q: Can I set a global value to an array or an object?**

A: Yes, you can set a global value to any data type, including arrays and objects. You can use an [Array Node](./array.mdx) or an [Object Node](./object.mdx) to create an array or an object, and then connect it to the `Value` input of the Set Global Node.
